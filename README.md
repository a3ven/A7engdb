# دیتابیس مهندسین

یک وب‌اپ تک‌فایلی (فقط `index.html`) برای جستجو، فیلتر و خروجی‌گرفتن از فایل اکسل دیتابیس.

## راه‌اندازی روی GitHub Pages

1. یک ریپوی جدید در گیتهاب بسازید (ترجیحاً **Private**، اگر پلن‌تان GitHub Pages خصوصی را پشتیبانی می‌کند).
2. فایل‌های `index.html`، `README.md` و `.gitignore` را آپلود کنید.
3. مسیر Settings ← Pages ← Source: `main` / root را انتخاب و Save کنید.
4. بعد از چند دقیقه لینک `https://USERNAME.github.io/REPO/` فعال می‌شود.

## استفاده

لینک را باز کنید و فایل `Engineers_Tehran_Database.xlsx` را از دستگاه خودتان انتخاب کنید.
فایل فقط داخل مرورگر خوانده و در حافظه‌ی همان مرورگر (IndexedDB) ذخیره می‌شود؛ دفعه‌ی بعد دوباره خودکار بالا می‌آید.
دکمه‌ی «پاک‌کردن دیتا» آن را حذف می‌کند.

## هشدار حریم خصوصی

**فایل اکسل را داخل ریپو آپلود نکنید.** صفحات GitHub Pages عمومی‌اند و هر فایلی که در ریپو باشد برای همه قابل دانلود است.
فایل `.gitignore` این ریپو فرمت‌های اکسل و CSV را نادیده می‌گیرد تا اشتباهاً commit نشوند.
